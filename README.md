
# Assignment 2 - ExpressJS Portfolio

## Project Description
This project is a personal portfolio website developed using Node.js, ExpressJS, and EJS templates. The website includes four pages and uses Bootstrap and custom CSS for styling.

## Website Pages
- Home
- About Me
- Projects
- Contact Me

## Technologies Used
- Node.js
- ExpressJS
- Express Generator
- EJS Templates
- Bootstrap 5
- Font Awesome
- CSS
- Git and GitHub

## Project Structure
- app.js - Express application configuration
- routes/index.js - Routes for all portfolio pages
- views/ - EJS page templates
- views/partials/ - Shared header and footer
- public/stylesheets/ - Custom CSS styling
- bin/www - Server startup file

## Features
- Four portfolio pages
- ExpressJS routing
- EJS templates
- Shared navigation bar and footer
- Responsive website design
- Bootstrap styling
- Font Awesome icons
- GitHub and LinkedIn links

## Installation Instructions
1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run npm install.
5. Run npm start.
6. Open http://localhost:3000 in your browser.
